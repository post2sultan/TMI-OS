# RADAR-05 — Watchlists and multilingual query planning

- Adds reusable Radar watchlists for brands, competitors, categories, markets, locations, channels, and campaign terms.
- Expands each scan into a bounded Arabic/English query plan.
- Caps every plan at eight queries by default to protect local resources.
- Deduplicates evidence across the complete plan before signal clustering.
- Keeps free-text Radar scans compatible with the existing dashboard.
